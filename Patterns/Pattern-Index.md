# 🎯 Pattern Selection Guide

### If the problem asks...

| Question | Pattern |
|-----------|---------|
| Find largest / smallest / count | Linear Scan |
| Compare from both ends | Two Pointers |
| Rearrange elements | Two Pointers |
| Longest / Shortest subarray | Sliding Window |
| Fast range sum | Prefix Sum |
| Search in sorted array | Binary Search |
| Fast lookup | Hashing |

# 📝 Interview Strategy

Before solving any problem, ask yourself:

1. Can I solve it using one traversal?
2. Does the array need to be sorted?
3. Can two pointers reduce nested loops?
4. Am I repeatedly calculating the same thing?
5. Can hashing reduce the time complexity?

The answer to these questions usually reveals the correct pattern.
